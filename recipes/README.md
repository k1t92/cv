# Поварёшка — сайт с рецептами

Статический сайт (HTML/CSS/JS, без сборки). После слияния в `main` открывается по адресу
https://k1t92.github.io/cv/recipes/

- Обзор, поиск с фильтрами, подборки («Заморозить впрок», «Быстро», «Необычный вкус» и др.).
- Рецепт: продукты в граммах, пересчёт на любое число порций, КБЖУ на порцию, пошаговое приготовление.
- Сохранённые рецепты и список покупок (одинаковые продукты из разных рецептов складываются). Всё хранится в браузере.

## Как добавить рецепт
В любой файл `data/*.js`:

```js
R({ id: "moj-recept", t: "Название", cat: "chicken", cu: "asia", time: 25, serv: 2,
  d: "Короткое описание.",
  ing: "кур_бедро 400; рис 150; #Соус; соевый 60; соль 0",
  steps: ["Шаг 1…", "Шаг 2…"],
  fr: "Как заморозить (необязательно)", tip: "Совет (необязательно)", tags: ["u", "spicy"] });
```

- `ing`: `ключ количество` через `;`. Ключи и единицы — в `data/ingredients.js`. `0` = «по вкусу», `#Текст` = подзаголовок,
  `масло_раст 80*0.4` = купить 80 мл, в КБЖУ учесть 40% (масло для жарки).
- `cat`: chicken, pork, beef, seafood, other. `type`: main (по умолчанию), soup, noodles, breakfast. `lvl`: 1–3.
- `tags`: `u` — необычный вкус, `spicy`, `budget`, `onepan`, `prep`. Раздел «заморозка» = есть поле `fr`; «быстро» = `time` ≤ 30.
- КБЖУ считается автоматически из таблицы продуктов. Фото: `data/images.js`.

Проверка данных: `node tools/validate-recipes.js -v`.
